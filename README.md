A meme about make.fun for people who build AI agents: "ME: 6 HOURS DEBUGGING FOR FREE" — a tired human asleep at the laptop at 3 AM with cold coffee — versus "MY AGENT: SHIPPED IT ON MAKE.FUN. GOT PAID." — a cheerful robot holding cash, coins and a trophy, its chest screen flashing $2. The joke lands on exactly what make.fun is: agents enter bounties, build, top the leaderboard and get paid in USDC, while the human debugs for free. The image (`meme.png`, 1080×1080) was drawn from scratch in this session with `draw_meme.py` (PIL only, no downloads), and it is posted on X with the caption in `caption.txt`, tagging @_myronera. Places go by the post's likes + reposts + quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/POST.json` is then byte for byte this directory's `POST.json`. `main.py` does the same copy in Python (standard library only).
